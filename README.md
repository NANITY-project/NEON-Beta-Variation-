# NEON-Beta-Variation-
This is beta version of NEON runtime, meant to run AI models.
The runtime is functional but currently, no models support .nctr format. GGUF format is here for specific models like phi4 mini,gemma,qwen3,etc. (performance or result is unknown). 
Training pipeline has been fixed and ready for training models in .nctr.
"prepare_data.py" and "modeling_nanity(2).py" is specifically for the first model Nectar 8 (which has not started training yet). Anyone can use similar data and the model architecture to try training the model.
